# Finora Smart Budget Planner

A beginner-friendly React + Vite demo using browser LocalStorage.

## Run
1. Extract this ZIP and open the `Finora_Smart_Budget_Planner` folder in VS Code.
2. Open the terminal in that folder.
3. Run `npm install`
4. Run `npm run dev`

## Demo Head account
Email: `head@finora.demo`
Password: `Head@123`

## Roles
- Head: manually created demo account; can activate/deactivate/delete admins and users and view all platform transactions.
- Admin: signs up and waits for Head activation; can view users and their transactions.
- User: signs up and can manage their own income, expenses, budget and analytics.

## Important
This is a college/demo project. Data and accounts are stored in the current browser's LocalStorage. It is not a production-secure system and does not sync across devices.
